# Niche Similarity and Spatial Co-occurrence in European Odonata

This repository contains data, scripts, analytical outputs, and rendered reports for the study **“Niche similarity and spatial co-occurrence in lentic and lotic European dragonflies and damselflies (Insecta: Odonata).”** The manuscript is in preparation.

The study examines how macroclimatic niche similarity is associated with broad-scale spatial co-occurrence in European dragonflies and damselflies, comparing species associated with lentic (standing-water) and lotic (running-water) habitats.

## Study Overview

The analyses include **119 species** (84 lentic and 35 lotic) across **2,317 50 × 50 km grid cells** in the study area. Species macroclimatic niches are represented as multidimensional hypervolumes. Pairwise niche similarity is quantified with the Jaccard index of hypervolume overlap; climatic niche distance is defined as **1 − Jaccard**. Spatial co-occurrence is the **absolute number of grid cells shared by each species pair**.

The study also evaluates differences in Jaccard similarity among lentic–lentic, lotic–lotic, and lentic–lotic pairs using a Kruskal–Wallis test and Dunn post-hoc comparisons, and uses mixed-effects models to examine ecological and climatic predictors of niche similarity. The corresponding reports are available in [`03_Docs_HTML/`](03_Docs_HTML/).

## Reproducibility

Run scripts from the repository root unless otherwise noted. The R scripts identify **R 4.5.1 (2025-06-13, UCRT)**. Package versions are recorded in script comments rather than a lockfile, so the repository does not automatically recreate a pinned environment. Recorded versions include `tidyverse` 2.0.0, `dplyr` 1.1.4, `GGally` 2.4.0, `geodata` 0.6.6, `raster` 3.6.32, `sf` 1.0.21, `hypervolume` 3.1.6, `rgl` 1.3.24, `ggplot2` 4.0.0, `rnaturalearth` 1.1.0, `rnaturalearthdata` 1.0.0, `Rcpp` 1.1.0, and `terra` 1.8.54. The pairwise-test report records `kableExtra` 1.4.0, `car` 3.1.3, `readxl` 1.4.5, and `dunn.test` 1.3.6. The mixed-model report records `tidyr` 1.3.1, `lme4` 1.1.37, `MuMIn` 1.48.11, `tibble` 3.3.0, `patchwork` 1.3.2, and `fmsb` 0.7.6, as well as versions listed above. The Mantel report loads `readxl`, `vegan`, `knitr`, `ggplot2`, and `patchwork`, but records no versions for those packages in that report. The richness-map script requires `sf`, `readxl`, and `ggplot2` and installs missing packages from CRAN without version pinning. The Python CLC script imports `rasterio`, `geopandas`, `numpy`, `pandas`, `matplotlib`, and `contextily`; it records neither a Python version nor package versions. No dependency lockfile is present.

The workflow is not fully automated from raw source data. In particular, the CLC GeoPackage consumed by the Python habitat-processing script is external and not included; the original elevation raster is also absent, although extracted elevation data are committed. Hypervolume construction downloads WorldClim through `geodata`, requiring network access. The scripts also contain path inconsistencies described below. The supplied processed data and analysis outputs therefore support parts of the workflow without guaranteeing a complete rebuild from raw inputs.

### 1. Data Preparation

- [`03_Processing_CLC_Python.py`](03_Processing_CLC_Python.py) processes CLC habitat areas, but reads `u2018_clc2018_v2020_20u1_geoPackage/DATA/U2018_CLC2018_V2020_20u1.gpkg`, which is not in the repository. Its CSV export statements are commented out, so it does not currently write the processed habitat tables as written.
- [`04_Data_format_variables.R`](04_Data_format_variables.R) combines occurrence, elevation, habitat, climate-range, and hypervolume-derived variables. Elevation inputs are available as processed data; the source DEM is not.

These inputs and scripts do not form a complete, self-contained raw-data preparation pipeline.

### 2. Hypervolume Construction

[`01_Calculate_Hypervolume.R`](01_Calculate_Hypervolume.R) extracts five WorldClim bioclimatic variables and constructs species hypervolumes, saved as `02_Hypervolume/hv_list_Lentic_sp.RData` and `02_Hypervolume/hv_list_Lotic_sp.RData`. WorldClim is fetched at runtime. The script contains a hard-coded `setwd()` to the repository name after paths have already been resolved from the working directory; as written, it is not a reliable one-command run from the repository root.

### 3. Pairwise Jaccard Similarity

[`02_Overlap_pairs_wise.R`](02_Overlap_pairs_wise.R) calculates pairwise hypervolume overlaps, including Jaccard indices, from the saved hypervolumes. From the repository root, its invocation is:

```r
source("02_Overlap_pairs_wise.R")
```

The script writes the three overlap CSVs in `02_Hypervolume/R_Overlap_pairs_wise/`. [`04_Data_format_variables.R`](04_Data_format_variables.R) contains the subsequent conversion to Jaccard matrices, but currently reads from `02_Hypervolume/Results_Overlap_pairs_wise/`, whereas the committed directory and the overlap script use `02_Hypervolume/R_Overlap_pairs_wise/`. Consequently, matrix regeneration is not reproducible with the scripts and paths as currently committed; the existing matrices are available under `01_Data/04_Data_Analysis/`.

### 4. Spatial Co-occurrence

[`05_Coocurrence.R`](05_Coocurrence.R) filters the lentic and lotic grids to the 2,317 study-area `ET_ID` values, aligns the grids, validates binary presence fields, and counts shared cells for each pair. It writes the within-group and intergroup pair tables under `01_Data/04_Data_Analysis/`. From the repository root:

```r
source("05_Coocurrence.R")
```

### 5. Mantel and Bipartite QAP Analyses

[`07_Mantel_Test_niche_coocurrence_odonata.Rmd`](07_Mantel_Test_niche_coocurrence_odonata.Rmd) reads the committed Jaccard matrices and the co-occurrence tables. Lentic–lentic and lotic–lotic associations use Pearson Mantel tests. The lentic–lotic association uses a Pearson correlation with bipartite QAP permutations, independently permuting species labels within each group while preserving the bipartite pair structure. All tests use a prespecified one-sided negative alternative and 9,999 permutations (seeds 20261014–20261016).

After installing the packages required by the report (`readxl`, `vegan`, `knitr`, `ggplot2`, and `patchwork`), run from the repository root:

```r
source("05_Coocurrence.R")
rmarkdown::render(
  "07_Mantel_Test_niche_coocurrence_odonata.Rmd",
  output_dir = "03_Docs_HTML"
)
```

The report writes `Mantel_results.csv` and `Figure_3_niche_cooccurrence.png`. The currently committed CSV is the source for the key findings above.

### 6. Mixed-Effects Models and Model Selection

[`08_Jaccard_LME_New_Data.Rmd`](08_Jaccard_LME_New_Data.Rmd) fits species-pair mixed models, ranks all-subsets models using AICc, and averages models with ΔAICc < 4. It creates separate plots for the three groups. Its input paths use `01_DATA/` (uppercase), while the repository directory is `01_Data/`; these paths resolve on Windows but may fail on case-sensitive file systems. The report should be rendered from the repository root on Windows with the listed model packages installed:

```r
rmarkdown::render(
  "08_Jaccard_LME_New_Data.Rmd",
  output_dir = "03_Docs_HTML"
)
```

This does not reproduce the exact committed Figure 4 JPG; the generated group-level files have different names and composition.

### 7. Figures

[`09_Species_Richness_Map.R`](09_Species_Richness_Map.R) sums binary presence across all 119 included species for each of the 2,317 aligned study-area cells and writes both the PNG and PDF map. Run from the repository root:

```r
source("09_Species_Richness_Map.R")
```

The PNG is committed at [`04_Figures/Figure_1_species_richness_119.png`](04_Figures/Figure_1_species_richness_119.png); the script writes `04_Figures/Figure_1_species_richness_119.pdf` when run, but that PDF is not currently committed. Figure 3 is generated by the Mantel/QAP report. Figure 4 is committed as [`04_Figures/Figure_4.jpg`](04_Figures/Figure_4.jpg), but its exact final composition is not reproducible from the scripts currently in the repository.
